# Collapsible PDF panel

Mode: Operate. Narrow extension of the existing conversation workbench. Preserve DESIGN.md, tokens, document contents and unrelated behavior.

User task: hide the right PDF contents panel to give the conversation more width, then reopen it without losing the selected document/page. A header toggle and panel close action use the incumbent Lucide icons and control styles. Citations reopen evidence automatically. On phones, the close action returns to Conversation and the existing PDF & evidence tab reopens it. Keyboard focus returns to the visible opener.

Evidence: controlled public synthetic workspace with the committed/public 120-page source; desktop open/closed, 1280px open/closed and phone open/closed captures. Build and browser regression tests cover width expansion, retained page, citation reopening and mobile focus. No new visual identity, comp, Figma asset, model work or backend change.
