# داکیومایند لوکال — DocuMind Local

[English](README.md) · **فارسی**

<div dir="rtl">

داکیومایند یک دستیار هوش مصنوعی آفلاین برای مطالعه و کار با فایل‌های PDF روی رایانهٔ شخصی شماست. جزوه‌ها و منابع درسی را وارد کنید، دربارهٔ آن‌ها سؤال بپرسید و صفحهٔ منبع پاسخ را با یک کلیک ببینید. همچنین می‌توانید فایل تکلیف یا برگهٔ آزمون را جداگانه وارد کنید تا برنامه سؤال‌ها را با استفاده از منابع انتخاب‌شده و به زبان سؤال پاسخ دهد.

رابط برنامه با **Next.js و TypeScript** ساخته شده است. **FastAPI، Ollama، Qdrant و SQLite** پردازش، مدل‌های محلی، جست‌وجو و ذخیره‌سازی را انجام می‌دهند. مسیر پیش‌فرض به اشتراک پولی چت‌بات یا کلید API سرویس‌های ابری نیاز ندارد.

## وقتی اینترنت بین‌المللی در دسترس نیست

**اگر دسترسی به اینترنت بین‌المللی در ایران قطع یا محدود شود و فقط شبکهٔ داخلی در دسترس باشد، داکیومایند می‌تواند پس از نصب و آماده‌سازی کامل، روی رایانهٔ شما کار کند.** برای استفاده از مدل‌ها و امکانات متنیِ نصب‌شده، نیازی به چت‌بات‌ها و سرویس‌های آنلاینی که به اینترنت بین‌المللی وابسته‌اند ندارید. حتی اتصال به شبکهٔ داخلی هم برای این کار لازم نیست؛ مرورگر به برنامهٔ محلی روی همان رایانه متصل می‌شود.

**نکتهٔ ضروری:** دریافت اولیهٔ مدل‌ها، وابستگی‌ها و ایمیج‌های Docker به اینترنت نیاز دارد. این آماده‌سازی را زمانی انجام دهید که امکان دانلود وجود دارد. فایل نصب نمی‌تواند هنگام قطع اینترنت، مدل یا نرم‌افزاری را که از قبل دریافت نشده دانلود کند. نصب مدل‌های اختیاری و به‌روزرسانی‌ها هم به دریافت فایل نیاز دارد. بستهٔ کاملِ قابل‌انتقال برای نصب روی رایانهٔ کاملاً بدون اینترنت فعلاً ارائه نشده است.

پیش‌نمایش وب از نسخهٔ عمومی فایل روی CDN استفاده می‌کند که به همین نسخهٔ ضبط‌شده متصل است. فایل‌های اصلی در پوشهٔ `docs/media/` هم وجود دارند و پس از دریافت پروژه می‌توان آن‌ها را آفلاین دید؛ خود برنامه از این CDN استفاده نمی‌کند.

پیش‌نمایش متحرک مستقیماً در این صفحه پخش می‌شود. ویدئو رابط فعلی برنامه، یک جزوه و آزمون فارسیِ عمومی و ساختگی، پاسخ واقعی مدل محلی، فرمول‌های ریاضی و اعلام کمبود اطلاعات را نشان می‌دهد. هیچ سند خصوصی دانشجویی در آن وجود ندارد. محاسبهٔ خودکار فقط برای این نمونهٔ مشخص عمداً فعال شده است؛ در حالت پیش‌فرض، بررسی ورودی‌ها لازم است.

## امکانات برنامه

- **گفت‌وگو با PDF:** سند یک‌بار پردازش و نمایه‌سازی می‌شود. سؤال‌های بعدی را بپرسید و صفحهٔ اصلیِ پشت هر ارجاع را بررسی کنید.
- **منابع درسی ← برگهٔ سؤال ← پاسخ:** منابع و برگهٔ آزمون جدا انتخاب می‌شوند. هر اجرا تا ۲۰ سؤال شماره‌دار را پردازش می‌کند و نتیجهٔ هر سؤال جداگانه بررسی و ذخیره می‌شود.
- **پاسخ چندزبانه:** زبان سؤال به‌صورت خودکار دنبال می‌شود یا می‌توانید زبان پاسخ، از جمله فارسی، را انتخاب کنید. نمایش راست‌به‌چپ، اعداد فارسی و OCR فارسی و عربی پشتیبانی می‌شوند.
- **نمایش و بررسی ریاضی:** فرمول‌های درون متن و مستقل با LaTeX نمایش داده می‌شوند. ابزارهای محدودشدهٔ SymPy و Pint برای جبر، مشتق، انتگرال، ماتریس و تبدیل واحد به کار می‌روند. ورودیِ برداشت‌شده توسط مدل را پیش از محاسبه بررسی کنید.
- **کمک به یادگیری:** توضیح حل، راهنمایی، تولید تمرین، بررسی راه‌حل شما، ذخیرهٔ موارد مطالعاتی و صف مرور.
- **ذخیره‌سازی محلی:** فضای کاری، خروجی و ورود داده، نتایج هر سؤال، وضعیت پیشرفت، توقف و تلاش مجدد و مدیریت اسناد روی رایانهٔ خودتان.

## نصب روی ویندوز

۱. [فایل ZIP پروژه](https://github.com/ErphanRajai/DocuMind-Local/archive/refs/heads/main.zip) را دریافت و استخراج کنید و پوشه را در محل ثابتی نگه دارید. اگر Git دارید:

<div dir="ltr">

```powershell
git clone https://github.com/ErphanRajai/DocuMind-Local.git
cd DocuMind-Local
```

</div>

۲. روی **`Install_DocuMind.cmd`** دوبار کلیک کنید. فایل نصب وجود Python، Node.js، Docker Desktop و Ollama را بررسی می‌کند؛ برای موارد نصب‌نشده نصب‌کنندهٔ رسمی را پیشنهاد می‌دهد؛ مدل‌ها را دریافت می‌کند؛ برنامه را می‌سازد؛ فایل‌های لازم برای جست‌وجوی محلی را آماده می‌کند و سلامت سرویس‌ها را می‌سنجد. پیام‌های مجوز ویندوز، راه‌اندازی اولیهٔ Docker/WSL یا درخواست راه‌اندازی مجدد را تکمیل کنید. پس از قطع دانلود یا راه‌اندازی مجدد، همین فایل را دوباره اجرا کنید.

۳. از میان‌بر **DocuMind Local** روی دسکتاپ یا فایل **`Start_DocuMind.bat`** استفاده کنید.

اجراکننده نشانی محلیِ قابل‌استفاده را باز می‌کند. روی رایانهٔ توسعه، نشانی `http://127.0.0.1:4400` استفاده شده است. پورت پیش‌فرض تنظیمات ۴۳۱۷ است و در صورت اشغال یا رزرو بودن آن، پورت‌های ۴۴۰۰ تا ۴۴۰۹ بررسی می‌شوند. نشانی چاپ‌شده توسط اجراکننده را ملاک قرار دهید.

این یک نصب‌کننده برای پوشهٔ پروژه است، نه یک فایل مستقل و امضاشدهٔ MSI. پوشهٔ پروژه را جابه‌جا یا حذف نکنید. بستن پنجرهٔ دسکتاپ، سرویس‌های برنامهٔ آن اجرا را متوقف می‌کند. اجرای دوبارهٔ نصب‌کننده، اسناد، پایگاه داده و مدل‌های قبلی را حذف نمی‌کند.

### چه چیزهایی دریافت می‌شوند؟

| بخش | کاربرد |
| --- | --- |
| `qwen3:4b-instruct-2507-q4_K_M` | مدل متنی محلیِ پیش‌فرض برای پاسخ و توضیح |
| `bge-m3` | تولید بردارهای جست‌وجوی چندزبانه؛ این مدل پاسخ گفت‌وگو را تولید نمی‌کند |
| وابستگی‌های Python و Node.js، ایمیج Docker و فایل‌های جست‌وجو | اجرای رابط، API، استخراج متن و بازیابی اطلاعات روی رایانه |

حداقل **۱۰ گیگابایت فضای خالی** در نظر بگیرید؛ دو مدل حدود ۳٫۷ گیگابایت حجم دارند. **۱۶ گیگابایت RAM** و در صورت امکان کارت گرافیک سازگار، نقطهٔ شروع پیشنهادی هستند؛ این اعداد حداقل سخت‌افزار آزمایش‌شده نیستند. اجرای مدل روی CPU کندتر است. برای محیط جدید، نصب‌کننده Python 3.12 و Node.js نسخهٔ ۲۲ یا جدیدتر را هدف می‌گیرد.

مدل‌های بینایی و پردازشگر پیشرفتهٔ ساختار و فرمول Docling اختیاری‌اند و دانلود جداگانه دارند. نصب اصلی آن‌ها را پنهانی دریافت نمی‌کند.

## امتحان کردن نمونهٔ فارسی

۱. فایل [study-fa.pdf](docs/examples/persian/study-fa.pdf) را به یک فضای کاری اضافه کنید و وارد **Study desk → Exam paper** شوید.

۲. فایل [exam-fa.pdf](docs/examples/persian/exam-fa.pdf) را به‌عنوان برگهٔ سؤال بارگذاری یا انتخاب کنید.

۳. جزوه را به‌عنوان منبع پاسخ انتخاب کنید. زبان را روی **Match question / exam** بگذارید یا **فارسی** را انتخاب کنید.

۴. دکمهٔ **Answer this paper** را بزنید. پاسخ‌ها، ارجاع‌ها و ورودی‌های برداشت‌شده برای محاسبه را بررسی کنید.

این نمونه دربارهٔ تعریف انرژی، دمای آب، یک معادلهٔ درجهٔ دوم و نام آزمایشگاهی که در جزوه مشخص نشده سؤال می‌پرسد. آخرین اجرای واقعی مدل، ۱۰ بررسی را گذراند: سه سؤال پاسخ گرفت و یک سؤال صریحاً با وضعیت **More information needed** مشخص شد. این آزمون کوچک فقط عملکرد همین مسیر را نشان می‌دهد و معیار دقت برای همهٔ امتحان‌ها نیست.

## حریم خصوصی و دقت پاسخ‌ها

- در تنظیم پیش‌فرض `DOCUMIND_LOCAL_ONLY=1`، سرویس‌های میزبانی‌شده و مدل‌های Ollama که پردازش را به سرویس ابری واگذار می‌کنند مسدود می‌شوند. فونت‌ها و فایل‌های جست‌وجو به‌صورت محلی آماده می‌شوند. اسناد، متن استخراج‌شده و پاسخ‌ها در مسیر پیش‌فرض روی همین رایانه می‌مانند.
- محلی بودن برنامه به معنای قطع فیزیکی شبکه یا کنترل ارتباطات سایر نرم‌افزارهای رایانه نیست.
- ارجاع به یک صفحه نشان می‌دهد چه منبعی بازیابی شده؛ درست بودن تمام جمله‌های پاسخ را ثابت نمی‌کند.
- تأیید محاسبه مربوط به ورودیِ داده‌شده یا برداشت‌شده است. OCR یا برداشت مدل از صورت سؤال می‌تواند اشتباه باشد. حل تضمینیِ همهٔ اثبات‌ها، دست‌خط‌ها و نمودارها از قابلیت‌های تضمین‌شده نیست.
- مدل، زبان، موضوع درس، کیفیت اسکن و سخت‌افزار روی نتیجه اثر دارند. پاسخ‌های مهم را با منبع اصلی یا پاسخ بررسی‌شده توسط مدرس مقایسه کنید.
- درخواست‌های پیش‌فرض با بودجهٔ ۸۱۹۲ توکن اجرا می‌شوند. کل کتاب یک‌جا داخل پیام مدل قرار نمی‌گیرد؛ بخش‌های لازم جست‌وجو و پردازش می‌شوند.
- کاربرد فعلی برای یک رایانهٔ محلی است؛ حساب سازمانی و استقرار چندکاربرهٔ عملیاتی ارائه نشده است.
- رابط قدیمی Streamlit به‌صورت جایگزین حفظ شده؛ ویدئوی بالا رابط اصلی Next.js را نشان می‌دهد.

## اگر برنامه اجرا نشد

گزارش آمادگیِ بدون تغییر فایل یا دانلود:

<div dir="ltr">

```powershell
.\Install_DocuMind.cmd -CheckOnly
```

</div>

- **Docker آماده نیست:** Docker Desktop را باز کنید، راه‌اندازی اولیه و WSL را تکمیل کنید و منتظر آماده شدن موتور بمانید.
- **مدل یا فایل لازم موجود نیست:** برنامه را ببندید و زمانی که دانلود ممکن است، نصب‌کننده را دوباره اجرا کنید.
- **رابط باز نمی‌شود:** نشانی دقیقِ چاپ‌شده توسط اجراکننده را باز کنید؛ پورت را ثابت فرض نکنید.
- **جزئیات خطای بک‌اند لازم است:** دستور `docker compose logs --tail 100 pdf_backend` را اجرا کنید. گزارش حاوی متن اسناد خصوصی یا اطلاعات محرمانه را منتشر نکنید.

برای تنظیم دستی، `.env.example` مرجع است. فایل `.env` موجود را بدون بررسی جایگزین نکنید و آن را در Git قرار ندهید. پیش از حذف فضای ذخیره‌سازی یا نصب مجدد، از داده‌های محلی و کارهای مهم نسخهٔ پشتیبان بگیرید.

## ساختار و بررسی فنی

| مسیر | مسئولیت |
| --- | --- |
| `documind-web/` | رابط Next.js و TypeScript، نمایش ریاضی و آزمون مرورگر |
| `pdf-summarizer-backend/app/` | FastAPI، کارهای پس‌زمینه، PDF/OCR، جست‌وجو و ابزارهای مطالعه و محاسبه |
| `pdf-summarizer-backend/evaluation/` | ارزیابی مدل واقعی، ریاضی، فارسی و عملکرد آفلاین |
| `pdf-summarizer-frontend/` | رابط جایگزین Streamlit |
| `setup_documind.py`، `scripts/install-windows.ps1` و `launcher.py` | نصب و مدیریت سرویس‌های محلی |

با محیط توسعهٔ Python که وابستگی‌های `pdf-summarizer-backend/requirements-dev.txt` در آن نصب شده‌اند:

<div dir="ltr">

```powershell
cd pdf-summarizer-backend
python -m pytest tests -q
cd ../documind-web
npm ci
npm run test
npm run build
$env:DOCUMIND_TEST_URL='http://127.0.0.1:4400'
npm run test:e2e
```

</div>

در دستور آخر نشانی واقعی اجرای خودتان را قرار دهید. آخرین بررسی محلی: **۲۱۷ آزمون بک‌اند، ۶۱ آزمون رابط، ۷ آزمون مرورگر و ساخت نهایی برنامه موفق بودند**. نمونهٔ فارسی با مدل واقعی و شش بررسی آفلاین در محدودهٔ یک فرایند هم موفق بودند. بسیاری از آزمون‌های واحد و مرورگر از پاسخ‌های کنترل‌شده استفاده می‌کنند؛ نصب پیش‌نیازها روی ویندوز کاملاً تازه و آزمایش قطع شبکه در سطح کل رایانه هنوز تأیید نشده‌اند.

فایل‌های خصوصی PDF، تنظیمات `.env`، پایگاه داده، مدل‌ها، فایل‌های موقت، گزارش‌ها و خروجی ساخت در Git قرار نمی‌گیرند.
