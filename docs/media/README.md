# Application previews

`documind-study-preview.mp4` is a silent recording of the actual Next.js study desk, made on 2026-11-02 with the local Qwen model and the public fixtures in `docs/examples/persian/`. It demonstrates selecting a separate exam and study reference, choosing Persian, processing four questions, displaying calculator-produced mathematics, reporting missing information and saving study items. Private workspace/document lists were filtered out before recording; model answers were not substituted or mocked. Automatic calculation was explicitly approved for this known synthetic example.

`documind-study-preview.gif` is an excerpt of that recording for automatic playback in GitHub's README image renderer. `documind-study-preview.jpg` is a still captured from the same live interface. The MP4 uses H.264 with its metadata at the start for browser playback. Playback timing is demonstration timing, not a performance benchmark.

The older `documind-demo.mp4`, `documind-demo.gif`, `document-chat.jpg` and `welcome.jpg` show the preserved Streamlit interface and remain as historical assets. They are not the current main-interface preview.
